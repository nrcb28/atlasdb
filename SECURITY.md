# Security policy

## Supported versions

Security fixes target the latest commit on `main`. Older commits and generated
artifacts are not guaranteed to receive fixes.

## Reporting a vulnerability

Please do not disclose credentials, database files, or a working exploit in a
public issue. Open a private GitHub security advisory for this repository. If
that option is unavailable, contact the repository owner privately through the
email address listed on the GitHub profile and include:

- affected commit or version;
- operating system and build configuration;
- minimal reproduction steps;
- impact and suggested mitigation.

Reports will be acknowledged as soon as practical. This project is educational
and the TCP server is not intended for untrusted networks; unauthenticated or
unencrypted network exposure should be included in the impact assessment.
